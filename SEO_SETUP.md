## Google Search Console

1. Go to <https://search.google.com/search-console>
2. Click `Add property`
3. Use the `URL prefix` option with `https://raferto1973.github.io/`
4. Choose a verification method:
   - `HTML file upload`: recommended for this static site
   - `HTML tag`: also valid if you prefer a meta tag
5. After verification, open `Sitemaps`
6. Submit `sitemap.xml`
7. Use `URL inspection` to request indexing for the homepage

## Bing Webmaster Tools

1. Go to <https://www.bing.com/webmasters>
2. Add site `https://raferto1973.github.io/`
3. Verify ownership with:
   - XML file upload, or
   - meta tag verification
4. Submit `https://raferto1973.github.io/sitemap.xml`
