## Publish On GitHub Pages

1. Push this repository to GitHub.
2. Open the repository settings.
3. Go to **Pages**.
4. Set **Build and deployment** to **Deploy from a branch**.
5. Select the `main` branch and the `/root` folder.
6. Save and wait for GitHub Pages to publish the site.

If you want the page to open from a repository subpath instead of a custom domain, this static setup already works without any build step.

### RF Travel Planner

Collaborative trip planning web app with itinerary management, group budgeting, settlement flows, trip documents, and installable PWA support.

- Status: Released as `v0.1.0`
- Live demo: <https://rf-travel-planner.vercel.app>
- Source code: Private repository
- Stack: Next.js, React, Supabase, CSS Modules, Vercel

Highlights:

- Collaborative travel planning with organizer, members, and invitations
- Detailed trip view with destinations, activities, transfers, accommodations, notes, and checklist
- Group finance features including shared pot, pending payments, settlement, and analytics
- Document upload, in-app preview, and PDF trip export
- Mobile-first refinements and installable PWA support with safe offline fallback

Technical work delivered:

- Implemented installable PWA support with manifest, icons, service worker, and offline fallback
- Hardened mobile trip-detail UX and fixed Android menu scrolling in production
- Improved Supabase auth flow and protected public PWA routes correctly
- Added finance and settlement improvements with persisted compensation tracking
